# SANGAM – Test Cases and Sample Data

## 1. Introduction

This document describes the basic testing process for the SANGAM website prototype. The purpose is to check website navigation, content visibility, registration access and mobile responsiveness.

## 2. Sample Test Cases

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Open the SANGAM website | Homepage loads successfully |
| TC02 | Check the website title | SANGAM name is displayed |
| TC03 | Click Explore Experiences | User moves to the activities section |
| TC04 | View learning activities | All four activity sections are visible |
| TC05 | Click community registration | Google Form opens |
| TC06 | Open website on mobile | Content adjusts to mobile screen |
| TC07 | Check About section | Project purpose is clearly visible |
| TC08 | Check contact section | Contact information is displayed |

## 4. Registration Testing

1. Open the SANGAM website.
2. Navigate to the Join Our Community section.
3. Click the registration button.
4. Check whether the external Google Form opens.
5. Verify that the form displays its registration fields.

## 5. Mobile Responsiveness Testing

The website should be checked on:
- Android smartphones.
- iPhones.
- Tablets.
- Desktop browsers.

The content, buttons and sections should remain readable and accessible on different screen sizes.

## 6. Expected Outcomes

- Website pages and sections load correctly.
- Navigation buttons work as intended.
- Learning activities are visible.
- Community registration opens the Google Form.
- Website content remains readable on mobile devices.

## 7. Testing Status

This document provides a basic test plan for the current SANGAM prototype. Actual test results should be recorded after performing the tests on the website.

## 8. Conclusion

Testing helps improve the usability, accessibility and reliability of the SANGAM website. Further testing will be conducted as new features are developed.
